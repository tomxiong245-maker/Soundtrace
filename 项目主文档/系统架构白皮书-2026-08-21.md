## 0 · 系统一分钟总览

**Soundtrace** = 本地跑、可追溯、真人拍板的多轨播客后期助手。

**三大不动特征**：
1. **Trace 可追溯** —— LLM 只负责一段（PREFERENCE 层判"剪哪些"），不是黑盒发布器；每一步写 JSON manifest 便于逐 stage 重跑
2. **本地跑** —— 全流程离线 · 公司音频不出机器（M2 硬红线，即使 M0 开发者模式也不能突破）
3. **学习进化** —— mentor gold + 用户人审 + 跨期案例三路沉淀

**六层 Skill · 按"边界不能跨"分**（不是按流程顺序）：

| L | 名 | 代码路径 | 硬边界 |
|---|---|---|---|
| L0 | `episode-triage-and-plan` · 门卫 | `代码/main/orchestrator/delivery_orchestrator.py::cmd_start` | plan.json 未冻结 · 下游一步不启动 |
| L1 | `feedback-engine` · 记忆 SOT | `代码/main/orchestrator/feedback_engine.py` | 所有反馈只走 `retrieve_before_decision` 一门 |
| L2 | PREFERENCE 层 × 3 skill · 剪哪些 | `新skill/candidate-{generation-and-gate,semantic-veto}` · `audition-and-delivery` | LLM 主 · gate 只兜结构 · 不碰参数 |
| L3 | `iterative-cut-refinement-v1` · 怎么剪 | `代码/稳定生产/challengers/iterative-cut-refinement-v1/` | Optuna 独占 · 不碰候选语义 |
| L4 | `learning-and-experience` + `learning-pattern-from-case-v1` · 学经验 | `代码/main/orchestrator/{label_learning_driver,build_labels_lake,case_memory}.py` | 只写数据源 · 不改生产代码 |
| L5 | `governance-and-tool-registry` · 治理 | `代码/main/tools/tools.json` + `代码/main/orchestrator/integration_governance.py` | 未登记 tool → `verify.sh` FAIL |

### Optuna 损失函数（`optuna_refine.py:438-441`）
```
loss = (5.0 - discontinuity)                       # signal · NISQA 越干净越低
     + 5.0 × max(1, still_present_count)           # 反作弊 · 每漏一个目标词 +5.0
     + (2.0 if not pre_check_pass else 0.0)        # 兜底 · 前 4 项 pre_check 挂
```
