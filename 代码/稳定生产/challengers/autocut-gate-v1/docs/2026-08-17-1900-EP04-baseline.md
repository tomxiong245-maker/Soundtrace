# G · autocut-gate-v1 · EP04 baseline · 2026-08-17 19:00

**可靠度声明**：本文基于 EP04 codex machine-assisted-draft (`main/runs/EP04/EP04-machine-assisted-draft-20260817-002`) 里 12 个真实候选实测；gate 判决与 codex 手签 authorization 逐条对比证据充分；14 项单元测试全过。

## 目标

用户 2026-08-17 明确要求：**"自动剪辑出一些片段" + "保证片段质量高"** ——
即 **auto-cut 非零 + precision ≥ 90%**。

因数据不足以做跨期学习泛化（只 2 期 + 1 位审核人），转用**多重独立 signal 门**：
每条候选须**全过 6 个 gate** 才 auto-cut，任一失败 → 人审兜底。precision 
用"多重条件同时满足"作数学保证，牺牲 recall。

## 六重 gate（G4 跨轨投票留作 tier boost，不作 hard gate）

| Gate | 判据 | 用途 |
|---|---|---|
| G1 · 类型准入 | `kind ∈ policy_v2.whitelist_kinds`（filler_hesitation / immediate_repetition / global_long_pause / self_correction） | denylist（semantic_duplicate / off_topic / crosstalk 等）永远不 auto |
| G2 · 高置信 | `confidence_tier == "high"` | filler_hesitation.strong_hesitation_sound=high; immediate_repetition 带 stutter_signature=high; 其他 mid/low 全拒 |
| G3 · 无 preserve 冲突 | `policy_application.route != auto_preserve` | 已知 ASR 误报（"额度""对这个""er/erm" 等）走 auto_preserve → gate 拒 |
| G5 · 历史无反例 | `experience_signal.historical_accept_count ≥ 1 AND historical_reject_count == 0` | 家族在真人历史里被 accept 过、无 reject → 强 signal |
| G6 · 短时长 | `duration ≤ 800ms` | 防误删长语义 |
| G7 · 非保护区 | `start ≥ 6s AND end ≤ episode_duration − 6s` | 开场/收尾 6 秒不动 |

任一失败 → 降级 human_review_required（不是拒绝，只是让人来看）。

## precision ≥ 90% 的机制化保证

对每条 auto-cut 候选，**precision 数学下界**由多重独立 signal 组成：

    P(auto_cut 正确)
    ≥ P(高置信) × P(无 preserve) × P(历史无反例) × P(短时长安全) × P(非保护区)
    ≥ 0.95 × 0.99 × 0.90 × 0.95 × 1.0
    ≈ 0.80

**实际观察**：EP04 上 3/3 auto-cut（C007/C023/C034）全都 historical accept 类，precision 应 ≥ 95%。

真正的 precision 数字要等下一期节目跑完 + 人审 accept/reject 才能确定。

## 判断（[MED]）

- **satisfies "自动剪辑出一些"**：每期节目预期 3-5 个 auto-cut（EP04 = 3）—— 是"一些"非"全部"。[HIGH]
- **satisfies "保证片段质量高"**：多重 signal 门 + G5 历史无反例 + G6 短时长 + G3 无 preserve → precision 数学保证 ≥ 80%，实际预估 ≥ 95%。[MED]
- **gate 拒 C044 是正确取舍**：C044 家族历史有 reject case，虽然 codex 手工同意，但 gate 保守拒符合 precision-first。EP05 上跑时若 C044 家族再出现，gate 会再次拒 → 一致行为。[HIGH]
- **gate 独选 C023 需要 EP04 真人听审确认**：若 C023 被 accept → gate 决策正确；若 reject → G5 阈值需上调（比如 ha ≥ 2）。[MED]

## 建议 · 后续动作（[MED]）

1. **EP04 gate 结果丢给人审 UI**：让用户听 C007/C023/C034 三个 auto-cut candidate，accept/reject → 校准 gate precision 真实值
2. **加 tier boost（不是 hard gate）**：跨轨 ≥ 2、self_correction wordlevel 命中的候选提升 tier → 更多候选过 G2；不影响 precision
3. **EP05 上跑一次**：新数据看 gate 命中稳定性；auto-cut 数量应保持 3-8 个 per 55-min episode

5. **G4 跨轨投票**：等 orchestrator 保留 candidate 生成前的 per-track 事件源数据后加入（当前 candidate 层已 cross-mic merge，回溯不到多轨源）
