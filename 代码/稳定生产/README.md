# 稳定生产/

对应《全局统筹记忆》图上「**稳定音频 Skill**」这一层——**真正做音频活的地方**。

> 当前各功能的状态和验收门统一见 `统筹全局/功能说明/`。本文件只解释执行层目录分工，不作为最新项目进度来源。

## 它跟其他目录的分工

```
剪辑项目/
├── main/              ← 编排层：状态机 + tool 注册表 + 每期 runs/
│                        它「只负责调用」——不做音频处理，不藏规则
│
├── 稳定生产/          ← 执行层：所有做音频活的脚本 + 剪辑规则
│                        （你在读的这个）
│                        - 降噪 / ASR / 候选生成 / 剪切 / 混音 / QC
│                        - 从「外部+内部学习」学到的规则以配置形态存在这里
│
├── 端到端学习剪辑/    ← EP03 那次的历史产物 + 原始 21 个脚本
│                        本身是「一次真实跑通的实验档案」，不是长期生产入口
│                        新脚本从这里演化到 稳定生产/scripts/，旧脚本保留可追溯
│
├── 从视频学习经验/    ← 外部知识循环产出：YouTube/官方文档学到的规则证据
├── 音频参考库/        ← 输入素材
├── 审核前端/          ← 分层人工审核 UI
└── 与AI的上下文/      ← 当前整体 AI 上下文；旧会话已归档
```

## 目录结构

```
稳定生产/
├── README.md                      你在读的这个
├── scripts/                       真实执行脚本（新代码住这里）
│   ├── generate_cut_candidates.py 从 ASR + 规则找候选（本轮新增）
│   └── (未来新脚本住这)
├── rules/                         剪辑规则配置（从两条学习线学出来的知识以此形态落地）
│   ├── candidate-generation.v1.json     ← 甲+乙混合初值
│   └── (未来 v2/v3 版本以文件平列)
└── references/                    本层用得着的引用（不重复外部学习成果）
    └── (指向 从视频学习经验/references/ 的相对链接或摘录)
```

## 三条边界

1. **`main/` 不藏规则**。所有"哪些该删、边界怎么扩、阈值多少"都在 `稳定生产/rules/*.json`。main 只按 plan.json 指定的 `rules_version` 拿快照。
2. **规则通过配置文件迭代，不通过改代码**。新一版规则 = 新一个 json 文件 + bump version。旧版本保留，可回滚。
3. **规则的来源要在配置里标清**——甲（AI 常识）/ 乙（外部学习证据）/ 丙（内部经验，本轮为空）——避免以后搞混"这个阈值是猜的还是有证据的"。

## 参考的项目结构惯例

- Dagster / Airflow：**编排层（`main/orchestrator/`）** 与 **作业代码（`稳定生产/scripts/`）** 分离
- DVC / Kedro：**流水线定义** 与 **参数配置（`稳定生产/rules/`）** 分离，参数版本化
- HuggingFace / MLflow：**代码** 与 **模型/数据版本** 分离——这里的"数据版本"对应我们的 `rules/*.v1.json`
