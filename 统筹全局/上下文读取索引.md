# 上下文读取索引

> 契约：`context-read-v1`（2026-08-15）
> 目的：让 Agent 用最小必要上下文工作，不牺牲 run、哈希和人工审核证据。

## 默认只读

1. `当前状态摘要.md`：当前 run、硬要求、阻塞点和下一道门。
2. `当前交接检查点.json`：最近一次交接/压缩前的结构化检查点。
3. 本任务对应的一份 `功能说明/Fxx-*.md`。
4. `当前剪辑偏好快照.md`：只有任务涉及候选、审核或标签学习时读取。

## 按需读取

- 需要操作步骤时：`Agent交付流程-从音频到成片.md`。
- 需要同步校验时：`版本同步与交付事实门.md`。
- 需要具体命令、哈希或失败证据时：对应 `main/runs/<episode>/<run>/` 或 Challenger。
- 需要历史比较时：`归档/` 和旧 run；默认不读。

## 不再默认全文读取

`全局统筹记忆.md`、`当前项目进度.md`、旧会话总结、run 日志和全部 Fxx 不属于每轮必读集合。
它们仍是权威/证据来源，但只有任务需要时才读取；当前状态摘要由同步脚本从
`当前项目进度.md` 的 `CURRENT_DELIVERY_FACTS` 生成。

## 安全规则

- 压缩上下文前先运行 `python3 main/orchestrator/context_checkpoint.py --write`。
- 读取摘要后若发现 `source_sha256` 变化或 `sync_status != PASS`，停止猜测并运行同步检查。
- 历史证据只移动到归档，不删除；媒体边界和原始文件只读规则不变。
