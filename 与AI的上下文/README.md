# 与 AI 的上下文

这个目录不再保存每次对话的长篇压缩记录。

默认只读 [`当前项目上下文.md`](当前项目上下文.md)。它保存整体目标、当前状态、正在进行的工作和权威文档路由。

更新规则：

- 产品或架构变化：更新 `统筹全局/全局统筹记忆.md`；
- 项目状态变化：更新 `统筹全局/当前项目进度.md`；
- 某项功能变化：更新 `统筹全局/功能说明/Fxx-*.md`；
- 命令、测试、日志和 SHA：写入对应 run 或 Challenger；
- 本文件夹的 `当前项目上下文.md` 只做跨对话整体摘要和指路；
- 旧会话文档已进入 `归档/`，默认不读，也不作为当前事实来源。

禁止继续新建按日期不断追加的“会话上下文压缩”文件。确需保留的原始会议或历史决策进入归档，并在权威文档中写清最终结论。
